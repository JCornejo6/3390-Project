# Alarm Clock

A desktop clock app built with React, styled after Apple's Clock app.

## Features

- **Clock** – shows the current time and date
- **Alarm** – set an alarm by hour, minute and AM/PM, with snooze (+5 minutes) and stop
- **Timer** – set a countdown with scroll wheels; a ring shows the time left, and it can be paused, resumed or repeated. The last 5 timers you used are saved so you can start them again with one click.
- **Settings** – change the clock color, text shadow, 12/24 hour time, showing seconds, the background image and the background blur

Settings and recent timers are saved in your browser.
